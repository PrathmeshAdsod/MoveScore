# AGENTS.md — IBM Bob Project Context
# Agentic Cinema

## Project Summary

**Agentic Cinema** is a choreography-first music generation tool for short-form creators.
The core innovation: dance first, music second. Upload a dance video, get original music composed around your movement.

## Development Context

This project was built using **IBM Bob** (Plan Mode + Agent Mode) as the development AI.

- **Plan Mode** was used to design the full architecture, verify API capabilities, and produce `PLAN.md`
- **Agent Mode** is used for all implementation across frontend and backend
- All major architectural decisions are documented in `PLAN.md`

## Tech Stack

- **Frontend**: Next.js (App Router, TypeScript) on Cloud Run
- **Backend**: Python / FastAPI on Cloud Run
- **AI — Video Analysis**: Gemini (multimodal, `gemini-2.5-flash`)
- **AI — Music Generation**: Lyria (via `google-genai` SDK)
- **AI Agent**: Google ADK single workflow agent (`ChoreographyMusicAgent`)
- **Storage**: Google Cloud Storage (temporary, 24h lifecycle)
- **Media Processing**: FFmpeg (audio+video combine)

## Pipeline

```
upload video → Gemini Files API → analyze_choreography (Gemini)
→ plan_music (Gemini text) → generate_music (Lyria) → combine_media (FFmpeg)
→ GCS signed URL → preview + download
```

## Important Constraints (from PLAN.md)

- No user accounts, no database, no Firebase
- Lyria timestamp instructions are musical directions — not millisecond-accurate sync
- Gemini video processes at ~1 FPS — fast sub-second movements may be under-sampled
- All AI calls happen server-side (backend) — no AI credentials in browser
- Production uses ADC (attached Cloud Run service account), not committed key files
